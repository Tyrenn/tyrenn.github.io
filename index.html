my personal craft

01

Hélice

A fluent, typesafe PostgreSQL query builder

French for propeller: a q and a b, from “query builder”, stacked on top of each other.

Sketch your schema as plain TypeScript types, then write queries that read like sentences. Autocompletion and result types follow along.

  • Typesafe & autocompleted
  • Customisable syntax
  • Zero runtime dependencies

02

Mousse

A Node.js web server framework built on µWebSockets.js

French for soap foam: thousands of bubbles, the requests.

HTTP routing, WebSockets and Server-Sent Events behind a single Context API, with middlewares, Standard Schema validation and generated OpenAPI docs.

  • HTTP, WS & SSE under one roof
  • Bring Zod, ArkType or Valibot as-is
  • router.test() in one call
pnpm add @moussejs/core more info →

03

Sépale

Svelte components, styled by families

French for sepal: the leaf that shelters the flower before it blooms.

Components first, CSS second. Pick an opinionated family, tune its few parameters, take your bundle home. No Tailwind.

  • Clear DOM structure & classes
  • Self-contained, tunable families
  • Theme workbench
